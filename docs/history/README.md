# Historical notes & audit archive

These are **point-in-time** documents kept for context — audit reports, fix
checklists, and incident write-ups from the hardening work (PRs #67 onward). They
describe the state of the code *at the time they were written* and are **not kept
up to date**. They were moved here from the repo root (audit Q-10) to keep the
root tidy; nothing in the code references them.

For the *current* open/deferred audit status, see **`docs/AUDIT_REMAINING.md`**
(one level up), which is the maintained ledger.
